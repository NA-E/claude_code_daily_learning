**CONCEPT — "Harness engineering" got its most detailed operational treatment yet: seven named failure patterns for agents in production, including a bulkhead pattern for plugin isolation and a seven-layer "allow-unless-denied" permission composition stack.** *Source: AI Agents Simplified (aiagentssimplified@substack.com), "7 Failures Nobody Warns You About Shipping An AI Agent," Hana, August 4, issue 63, referencing Ken Huang's book "OpenClaw AI in Production."* Two specifics worth keeping: (1) an empty allow-list in a deny-first matcher usually means "permit everything," not "permit nothing" — the precedence stack runs built-in defaults → global config → per-agent config → channel policy → sandbox policy → subagent depth limits → per-session overrides, and tool group expansion is single-level only, not recursive; (2) context compaction reliably destroys UUIDs, file paths, container IDs, and API endpoints even though it preserves prose — the fix is triggering compaction at 70-80% of the context window (not the ceiling), chunking by token weight rather than message count, and hard-instructing the summarizer to reproduce opaque identifiers verbatim.
