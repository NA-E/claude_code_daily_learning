**FEATURE — iOS simulator support lands in beta for Claude desktop.** *Same source.* macOS only, requires Xcode: Claude can build your iOS app, launch the simulator, and verify the result without leaving the session. docs: code.claude.com/docs/en/desktop-ios-simulator.

**FEATURE — Claude desktop app reaches Linux (beta): Ubuntu and Debian.** *Same source.* Runs sessions in parallel with Git isolation, monitors CI with auto-fix and auto-merge, reviews diffs inline — and shares the same config as the CLI, so CLAUDE.md, MCP servers, and skills carry over with no separate setup.

**TOOL — Claude's "Record a Skill" feature turns a screen recording into a reusable automation.** *Source: The Rundown (hi@learn.therundown.ai / news@daily.therundown.ai), July 27.* Exact steps: (1) install Claude in Chrome, pick a repeatable task; (2) open Claude Cowork, click +, select "Record a Skill," then do the task normally; (3) narrate out loud — Claude learns from your screen, your actions, and what you say; (4) click "Save the skill," then test it on a fresh instance of the task. Pro tip from the guide: attach the new skill to a daily or weekly recurring task so it runs unattended. Full guide: app.therundown.ai/guides/automate-tasks-with-claudes-record-a-skill-feature.
