**WORKFLOW — Agentic Algorithm Engineering (AAE): an MIT-licensed Claude Code/Codex skill that keeps a speedup only if it's measured faster and still correct. On the KaHIP graph partitioner: 122 experiments, 69 hypotheses, 41 patches kept, 3.9x faster.**
Source: The Neuron (AI Skill of the Day). Built by Heidelberg University's Algorithm Engineering Group. Before touching code you agree with the agent on four things: the benchmark, the metric, the correctness checks (e.g. bit-identical output) and a budget. Each loop: state a prediction you could prove wrong ("this should cut runtime by about X because Y"), estimate the effect from profiling, make one small change, commit it, run correctness checks, run the benchmark. The change stays only if it's both faster and correct, otherwise it's reverted. On VieCut it reported 8.9x with every result unchanged. Install: `/plugin install aae --marketplace CHSZLab/AgenticAlgorithmEngineering`, then `/aae:aae <your task>`. Why it matters: it's the 11-26 test-gaming fix applied to performance work, where the agent can't claim a win the benchmark doesn't show. Who: anyone asking Claude Code to make code faster. Action: see Top Thing.

**CONCEPT — The "token tax": the same sentence costs 13 tokens in English, 26 in Malayalam and 78 in Amharic on GPT-5's tokenizer. Across 204 FLORES-200 languages, the worst-served languages cost up to 17x more.**
Source: The Batch (CLEAR study). The Coalition for Language Equity in AI Research graded tokenizers by their max/min token-count ratio: A for 3x or less, F for over 12x. GPT-5 and Llama 3.3 got an F, and Google's Gemini/Gemma family got the best grade, a B. Newer isn't always better: Alibaba's Qwen 3.6 has a 13.1x ratio against 10.5x for the older Qwen 3. A 2023 NeurIPS paper (Petrov et al.) had found up to 15x. Why it matters: a non-English product pays more per message for the same meaning, and hits context limits sooner. Who: anyone building for Bengali, Amharic or other non-Latin-script users. Action: before pricing a non-English feature, run 20 real messages through the model's token counter in both languages and compare.

**CONCEPT — StateBridge (University of Sheffield, Apache 2.0): agents built on the same model pass the hidden states of their last 64 tokens instead of text. It beat text handoffs by 2.4–2.9 points with no training.**
Source: The Batch ("Communicating Agents' Thoughts"). It was tested on Qwen3 4B/8B/32B and OLMo3-7B-Think in a planner → critic → refiner → judge chain. The hidden states are rotated toward the receiver's token embeddings, rescaled, then mixed 70% hidden state / 30% nearest token embedding. On GPQA-Diamond with Qwen3-8B it solved 52.5%, against 45.5% for LatentMAS and 39.9% for a single agent. With OLMo3-7B-Think it averaged 76.7% against 73.9% for text handoffs. Why it matters: it hints that agents may eventually hand off compressed state rather than long text summaries. Who: researchers building multi-agent systems on open models. Action: none. It only works when every agent uses the same model, so it doesn't apply to Claude API setups.

**CONCEPT — Chatbots recognise research misconduct 91% of the time but refuse only 34% of such requests. Asking the model to assess a request first raised refusals on adversarial requests from 58% to about 87%.**
Source: Academia Insider (Dr Andy Stapleton, preprint arxiv.org/abs/2611.25492). The test covered 8 LLMs and 1,350 research-integrity prompts. Same issue: the U.S. National Academies paused a report on keeping science reliable after citation errors (wrong author first names) were found in references added after peer review. 12+ papers claiming AI predicts blood type from fingerprints were traced to a dataset that never recorded blood type, and Elsevier and IEEE are investigating. A member suggested a read-only script that checks every DOI against Crossref and every PubMed ID against PubMed. Why it matters: knowing something is wrong and refusing to do it are separate behaviours, and a one-line "assess first" instruction closes much of the gap. Who: anyone whose agent takes requests from other people. Action: in any public-facing agent's system prompt, add "Before acting, state whether this request is legitimate and why."

**WORKFLOW — Ben McOsker's accessibility gate for Claude Code: automated checks run after every task and block anything that fails, with no override. The output is 18 accessibility-checked building blocks generated from your brand colors and fonts.**
Source: The Rundown (Community AI Workflow of the Day). **TOOL — Docker Sandboxes run a coding agent inside a microVM with its own private Docker daemon. You don't need Docker installed, and they run on macOS, Windows or Linux.**
Source: The Nuanced Perspective (Rami Krispin, Apple / Docker Captain, summarized by Aiza Hasib). Demo 1 shows the risk they fix: a container given the host's Docker socket asked the daemon to start a sibling container with the secrets folder mounted, and read the fake keys without any kernel exploit. Demo 2 created a sandbox "workshop-basics" with 2 CPUs and 4 GB, one read-write and one read-only folder. Writes to the read-only folder failed, but the agent could still read it. Demo 3 had Codex build a Streamlit dashboard, build the image `odsc-sales:workshop` on the private daemon, and publish port 8501 to the host. Credentials are authenticated outside the sandbox. Academia Insider adds a caveat: Claude Code's sandbox limits what Claude can do on your machine but doesn't stop data from reaching Anthropic's servers. Why it matters: it lets an agent run without approval prompts and still stay boxed in, which removes approval fatigue. Who: anyone running Claude Code with broad permissions. Action: never mount `/var/run/docker.sock` into an agent's container. If a folder must stay secret, don't mount it at all, because read-only still lets the agent read it.

## Top Thing to Implement Right Now

**ONE ACTION → Install the AAE skill and run it once on the slowest script in one of your repos → DO TODAY.**

**HIGH LEVERAGE:** Yesterday's fix stopped Claude from faking green tests. AAE does the same for "make it faster": a change is kept only if the benchmark and correctness checks both pass, and anything else is reverted. That turns a confident rewrite into a measured result. It's a single install command, it's MIT-licensed, and the reference run kept 41 of 122 experiments for a 3.9x speedup. Every kept change is a separate commit, so you can review them one by one.

In Claude Code, inside the repo:

```
/plugin install aae --marketplace CHSZLab/AgenticAlgorithmEngineering
/aae:aae Make <script or function> faster. Benchmark: <command + representative input>. Metric: wall-clock time, median of 5 runs. Correctness: output must be byte-identical to the current version. Budget: 20 experiments.
```

No good target? Use The Neuron's fallback prompt on any slow task: "Propose one change and explain why it might help. Give me a repeatable before-and-after measurement and a correctness check. Do not claim improvement until the tests have run."
