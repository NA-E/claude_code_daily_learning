**CONCEPT — Containment has three layers, per an OpenAI Agent Security engineer: lock down the environment, align the model, and monitor with evidence the agent cannot touch.** Source: The Neuron, "not just the sandbox" (theneuron.ai/news/openai-agent-security-new-rules-containing-ai-agents). Layer one covers sandbox, tools, credentials, networks, and connected services. Layer two is the model respecting what it is authorized to do while independent controls still enforce the limits. His organizational point is a "culture of reasonable paranoia" with safety researchers and security teams working as one unit. Action: for this routine, write down what each layer is today (repo scope, the Claude GitHub App permissions, and the git log as external evidence).
