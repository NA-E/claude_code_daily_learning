**CONCEPT — The Claude usage habits that cost you money (RoboNuggets' 23 mistakes).** Source: RoboNuggets newsletter (YouTube: youtube.com/watch?v=gvESqM6s0kM; free guide on skool.com/robonuggets-free). **CONCEPT — Resilience for AI-powered software (Sam Newman, via The Pragmatic Engineer).** Source: The Pragmatic Engineer, excerpt from "Building Resilient Distributed Systems" (newsletter.pragmaticengineer.com/p/building-resilient-systems). Define a recovery point objective (max data loss) and recovery time objective (max downtime) per service; the four disaster-recovery patterns are backup-and-restore, pilot light, warm failover and multisite active-active. For AI: degrade gracefully when the model is down or you are rate limited, keep a backup vendor (OpenAI models on Azure, Anthropic's via Google's Gemini Enterprise Agent Platform), run evals so you are surprised before your users, set timeouts by tokens generated, make spend visible per person, and review AI vendors more often than normal ones. **WORKFLOW — Temporal versioning for production RAG (The Neural Maze, Substack Brain Lesson 3).** Source: The Neural Maze (theneuralmaze.com/p/temporal-versioning-for-production). When an article changes, close old passages by setting `valid_to` instead of deleting, and insert new ones; a partial unique index (`CREATE UNIQUE INDEX uq_passages_article_chunk ON passages (article_id, chunk_index) WHERE valid_to IS NULL;`) allows one current version per chunk. A SHA-256 content hash stops unchanged articles before any embedding call. The feed poller sends `If-None-Match` and `If-Modified-Since` so unchanged feeds return 304, and saves the new ETag only after events are sent. Failures are recorded from Inngest's `inngest/function.failed` event, and an 8-tool MCP server wraps it (`claude mcp add substack-brain -- uv --directory /absolute/path run kb-mcp`). Action: copy the "save the cursor last" ordering into any poller you own.
