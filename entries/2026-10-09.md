**TOOL — FLUX 3 Action (Black Forest Labs): 7B world-action model, 42.9% on RoboLab-120, open weights on Hugging Face.** Source: The Batch. **CONCEPT — HYSET picks tool sets, not tools: 69.9% task success vs 61.8% for the best baseline.** Source: The Batch (Shanghai Jiao Tong and Hong Kong Polytechnic). Scores pairwise compatibility between tools plus whole-set relevance to the query, trained on ToolBench (about 14,000 tools). Recall@5 88.6% versus ToolGen's 81.4%. Why it matters: it explains why adding a fifth overlapping MCP server can make an agent worse. Action: audit your connected MCP servers for overlap and disable any duplicate of the same function.

**TOOL — Fly.io Sprites: 40+ connectors that keep API keys out of the agent's sandbox.** Source: Fly.io newsletter (fly.io/sprites/ecosystem/). You connect a service once in the dashboard and the Sprite calls it through the Fly.io gateway, so the key never lands inside the Sprite; each connector is fenced to its endpoints (a Neon key can branch databases, not run the account). 16 connectors added in 3 weeks, SDKs in four languages, nine coding agents preinstalled, Claude Managed Agents can run in Sprites (docs.fly.io/sprites/integrations/claude-managed-agents), and the Claude Code plugin github.com/superfly/sprites-claude-plugin adds `/sprites-inspector`. The Sprites Block Device is in private beta. Action: for any agent holding live keys, move the key to a gateway pattern like this.

**CONCEPT — Voice agents fail at turn-taking and actions, not transcription: five dimensions and a Pass@1 gate.** Source: The Chai & AI Community (The Nuanced Perspective), "Where Voice Agents Actually Break". Dimensions: perception, turn-taking, latency, action, recovery. Full-Duplex-Bench-v3 has 100 recordings from 12 speakers and passes a scenario only if every tool and argument is exactly right. A caller who corrects "Tuesday" to "Thursday" can leave the agent acting on Tuesday; "please do not cancel" with "not" dropped has a low word error rate and the opposite meaning. Fixed 500 to 800 ms silence thresholds should become one signal beside a context-aware turn model. Action: turn every production failure into a regression test and give each interaction one correlation ID.
