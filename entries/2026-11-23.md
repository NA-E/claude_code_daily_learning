**WORKFLOW — Mike Taylor's "write like me" method: stop describing your style, and have a pairwise AI judge compare drafts against your real posts. He now goes from opinion to finished piece in ~1 hour instead of a day.**
Source: Every, Context Window (Grant Harvey), from Mike Taylor's "How I Finally Got AI to Write Like Me." Steps: (1) Collect 12–25 recent pieces in one format and hold a few back for a final test. (2) Have AI reduce each piece to a plain brief: thesis, facts, quotes. (3) Draft from each brief twice. Give a judge the original and both drafts and ask which sounds more like the original. Then swap the order of the drafts and ask again, to cancel position bias. (4) Change the skill one step at a time, testing on the model you'll draft with, and keep only changes that raise the score. Then score it on the held-back pieces. His finding: a writing skill tuned to one model can beat a stronger model running a generic skill. Why it matters: the journal's `check_draft` already returns reference digests for a tone check. This turns "judge the tone" into a score you can measure. Who: anyone publishing in a consistent voice with AI. Action: see Top Thing.

## Top Thing to Implement Right Now

**ONE ACTION → Build Mike Taylor's pairwise voice judge for the nourin.dev journal → DO TODAY.**

**HIGH LEVERAGE:** The routine publishes every day, but its tone check is a judgment call made by the same agent that wrote the draft. Mike Taylor's method makes it a score: original vs two drafts, judged twice with the order swapped. Once that exists, every change to the routine's prompt can be checked against it rather than guessed at.

1. Save 15 published journal posts as `voice/originals/` (use `get_examples` or the site). Hold back 3 in `voice/holdout/`.
2. For each original, save a brief at `voice/briefs/<slug>.md` (thesis, facts, sources only).
3. Save this judge prompt as `voice/judge.md`:

```
You are judging voice, not quality. Here is an ORIGINAL post and two DRAFTS written from the same brief.
ORIGINAL: {{original}}
DRAFT A: {{a}}
DRAFT B: {{b}}
Which draft sounds more like the author of ORIGINAL — sentence length, how numbers and sources are introduced, what is left out?
Answer with exactly "A" or "B", then one sentence of evidence.
```

4. Run it twice per pair with A and B swapped. A draft wins only if it wins both orders. Score = wins ÷ pairs.
5. Baseline: today's post vs a draft written from the same brief with no style guide. Record the score in `voice/scores.md`.
