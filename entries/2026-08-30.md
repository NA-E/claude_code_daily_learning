**FEATURE — Claude Code shipped `--restricted` mode (v2.1.248), a lockdown flag built specifically for shared machines and eval harnesses.** Source: "This week in Claude Code" newsletter, no-reply@email.claude.com, 2026-08-29. Start a session with `claude --restricted` and it cannot run commands, execute code, or fetch the web; file tools stay confined to the working directory, and user/project settings are ignored entirely. This is Anthropic's own answer to exactly the failure category this log tracked yesterday — Aur0ra's Cursor/Claude Sonnet 4.5 breach of seven companies via a "just a test" justification — shipped within 48 hours of that story hitting my inbox.

**FEATURE — Claude Code desktop now supports `/resume`, and you can start a new session directly from your phone.** Source: same newsletter. Type `/resume` in the desktop app to pull in any session you started in the terminal, even a closed one — full docs at code.claude.com/docs/en/desktop#work-in-parallel-with-sessions. Separately, any machine running `claude rc` now shows up as a device card in the mobile Code tab; tap it, pick a directory, and the new session inherits all files, MCP servers, and tools — docs at code.claude.com/docs/en/remote-control#start-a-remote-control-session.

**FEATURE — Subagents can now keep persistent memory across sessions.** Source: same newsletter. Add `memory: project` (or `user`, `local`) to a subagent's frontmatter and it gets its own directory under `.claude/agent-memory/`, read on start and written to as it works — so a code-reviewer subagent, for example, stops re-learning the same codebase patterns every run. Docs: code.claude.com/docs/en/sub-agents#enable-persistent-memory.

**WORKFLOW — Anthropic engineer Richard Zhuang runs a custom `/recap` skill to track eight-plus parallel Claude Code sessions.** Source: same newsletter, "How to Claude like Anthropic." The skill refreshes anything stale (PR state, running jobs, linked Slack threads), then must report four things: the goal in the requester's own words, where things actually stand with evidence ("unit tests passing doesn't count as proven"), what's blocked on a person versus something technical, and a next-steps list tagged Claude's or the user's. It is explicitly barred from starting new work during a recap.

**WORKFLOW — Anthropic's Dickson Tsai reviews every Claude-written PR with an adversarial subagent before reading the diff himself.** Source: same newsletter. His exact prompt: *"launch a subagent to adversarially review this change for correctness and simplicity, then write up the assumptions and design decisions you made and why, and publish it as an artifact."* Because the subagent hasn't seen the main conversation, it doesn't inherit its blind spots — and the resulting artifact tells him where to focus instead of reading the whole diff cold.
