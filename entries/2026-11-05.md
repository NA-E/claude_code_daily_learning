**NEWS — Anthropic: 50 analysts followed their AI agent's hidden coin-flip lean on 86% of decisions.** Source: The Neuron (anthropic.com/research/agents-judgment-calls). **WORKFLOW — "Sort your agent's actions by what happens if it's wrong": a four-rule approval prompt.** Source: The Neuron "AI Skill of the Day" (dev.to/hassann/ai-agent-guardrails-approval-gates-and-blast-radius-control). The scene: an agent at 3 AM decides a ticket is an escalation and emails an accurate summary to the user's boss, because nothing sat between its decision and the send. The test: if the agent got this wrong 100 times, would that be acceptable? Rules: (1) safe and reversible (reads, searches, drafts) runs; (2) hard to undo (sends, deletes, payments) needs approval; (3) not sure counts as 2; (4) cap how many type-2 actions per hour. Why it matters: it is the concrete fix for the self-approval finding (11-03). Who: anyone running an agent with write access. Action: see Top Thing.

**CONCEPT — The Neural Maze lesson 6: a bounded research agent with three hard stopping conditions.** Source: The Neural Maze (theneuralmaze.com/p/durable-research-agents-in-production). The loop stops at a maximum of 3 rounds (never more than 5), a USD budget (default $0.25), or any round after the first that finds zero new passages. Each round is a durable Inngest step, so a failure retries only that step. Reports are checked by deterministic citation checks (FM-1 to FM-3) and judges (FM-4, FM-5) before saving; the server grows to 13 MCP tools; `make start` with `INNGEST_DEV=0` connects out to Inngest Cloud over a WebSocket, so no tunnel is needed. The budget caps the loop, not the final report, so the bill can run slightly over. Why it matters: it is a ready pattern for any scheduled agent, like this routine. Who: people building research agents. Action: copy the three stopping rules into any loop you run.

## Top Thing to Implement Right Now

ONE ACTION: Paste a four-rule approval policy into the instructions of every agent that can send, delete or pay. HIGH LEVERAGE: three separate stories today (CrowdStrike's kill switch, Wells Fargo's liability terms, Anthropic's 86% finding) point the same way: the agent's own judgment and a tired human's quick approval are both weak gates. The policy costs nothing and works on any agent. DO TODAY: add this text to your agent's system prompt or project instructions: "1. Safe and reversible (reads, searches, drafts): run without asking. 2. Hard to undo (sends, deletes, payments, permission changes): show me the exact request and wait for my approval. 3. If unsure which category, treat it as 2. 4. Take no more than 3 category-2 actions per hour." Then ask it to list the last five things it did and which category each fell into. Time-box: 15 minutes.
