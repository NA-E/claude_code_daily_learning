**WORKFLOW — theneuron's "AI Skill of the Day": periodically audit your saved AI instructions for ones that now contradict each other.** Source: theneuron@newsletter.theneurondaily.com, 2026-09-24/25, citing Every's Katie Parrott. Saved corrections and old templates accumulate until an assistant is trying to satisfy simultaneous, conflicting requirements, and output quality degrades without an obvious cause. Fix: run an audit, archive what's outdated, rebuild a smaller set of instructions that actually agree, and stop saving every intermediate draft. Exact copy/paste prompt: "Review the instructions and examples in [project/folder]. Identify duplicated, conflicting, and outdated rules, citing the specific files and short excerpts. Propose what to keep, archive, or rewrite. Do not modify files until I approve."

**TOOL — "The Numbers Desk": three Claude Skills that turn a raw spreadsheet export into a $3K/month analyst's report.** Source: theaibreak@substack.com, "Tutorial: Replace Your $3K/month Data Analyst With a Claude Skill," 2026-09-25. Setup is two one-time prompts (a "METRICS CORE" interview that fixes your 5 real numbers and traps like refunds/test rows/timezones, then an "EXPORT MAP" per file that pins the exact column/formula for each metric) followed by three reusable skills: Report Desk (one-page monthly report with math shown), Delta Watch (what changed since last period, timing noise removed), and Ask the File (plain-English questions with the calculation shown). Skills install as a `SKILL.md` file — in the Claude app via Settings → Skills → upload a ZIP; in Claude Code via `~/.claude/skills/<name>/SKILL.md` (personal) or `.claude/skills/<name>/SKILL.md` (project, travels through git).
