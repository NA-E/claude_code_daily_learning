**CONCEPT — The Neural Maze's practical guide to context compaction: trigger at about 75%, and Claude Code compacts after an hour idle, before the prompt cache expires.** Source: The Neural Maze (guest author Jason Rametta, Zapier). Compaction shrinks a session so it fits the window again. OpenCode, Pi and Claude Code each do it differently, and the differences change results. The example uses Fable 5.2's 1M-token window, compacting at 75% (750K) and keeping a buffer because output counts against the window. Claude Code "can compact a large session after about an hour idle, right before the 1-hour prompt cache would expire, so your next message doesn't have to reprocess the whole history uncached." Strategies: an LLM summary with a custom prompt; stripping tool calls before summarizing to cut cost, or keeping them so expensive calls don't repeat; or a "running notebook" carried forward instead of a summary (credit Robin Salimans, Zapier). For recall afterwards, give the model a table of contents of the old conversation so it can load details through tool calls, or dump history to files on disk it can search. Why it matters: it explains the idle-compaction feature from 11-11 (v2.1.314, sessions over 200K tokens). Who: anyone with long Claude Code sessions. Action: before a long session goes idle, write a handoff note yourself (11-18 prompt) instead of relying on the automatic summary.
