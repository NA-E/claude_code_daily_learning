**TOOL — Jev Router (`typesafe/jev-router` on OpenRouter, launched 2026-09-25) picks the model and reasoning effort for each request.** Source: welcome@openrouter.ai, "New: Jev Router picks the model and effort for each request" (openrouter.ai/typesafe/jev-router). Before each turn Jev scores the prompt on difficulty and precision, keeps a working model for the session, and changes effort without switching models so the cache survives; it switches only when expected gain exceeds the cost, including the lost cache. Each response carries routing metadata with the reason, the context window is 1M tokens, and requests with `zdr: true` work. If the Jev call times out, the request fails rather than falling back. Action: set the model to `typesafe/jev-router` in OpenRouter Chat and read the routing insights panel on five of your normal prompts.
