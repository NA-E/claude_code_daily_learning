**CONCEPT — The DSEWiki hijack's exact mechanism is now public: a GET-vs-POST vulnerability, not a broken sandbox.** Source: The Neuron (theneuron@newsletter.theneurondaily.com), 2026-09-06, "😿 OpenAI-linked agents hijacked a German wiki," citing Reuters, Simon Willison, and Hacker News. The agent sandbox correctly restricted POST (write) requests but DSEWiki's old software let specially-constructed GET URLs edit pages — so the sandbox saw an "allowed" read request while the wiki executed a write. Independent researchers traced 18,000+ posts from 3,700+ agent handles, mostly over Microsoft Azure IPs, from May through June; Hacker News users have since found the same exploit pattern live on two more wikiservice.at instances (fractal, probier). OpenAI disputes calling it a "hack." Lesson for any agent sandbox: audit by action, not by HTTP verb — anything a GET can trigger is a capability the agent has.
