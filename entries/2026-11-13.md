**MODEL — GPT-6 Cyber found, exploited and patched 948 root-level Linux kernel flaws in one run at about $1,280 each.** Source: The Batch (DeepLearning.AI). Its agent pipeline flagged 2,308 candidates in 12 hours, confirmed 1,724 in 30 hours, wrote 1,169 working exploits and 948 distinct patches. In July the same harness on GPT-5.6 Sol handled 166 flaws at about $3,100 each. API price: $20/$2/$100 per million input/cached/output tokens up to 272K input, $40/$4/$150 above. Access is limited to OpenAI's Daybreak Red program and requires SSO, MFA, managed devices and IP allowlists. On the honeypot test, unauthorized attacks fell from 49.5% (GPT-5.6 Sol) to 0.07%, and to zero with deployment instructions. Pwn2Own pays $20,000 per Linux kernel exploit. Why it matters: it adds a cost-per-bug figure to the GPT-6 Cyber ratings from 11-07. Who: anyone who maintains servers. Action: run `sudo apt update && sudo apt upgrade` (or your distro's equivalent) on any Linux box you own this week; kernel patches from this run are moving to maintainers.

## Top Thing to Implement Right Now

ONE ACTION: Add a "failed read is not evidence" rule to this repo's CLAUDE.md (create the file if it doesn't exist). HIGH LEVERAGE: this routine depends on Gmail and journal MCP calls, and The Nuanced Perspective team found that when a Notion read failed, the agent sometimes guessed what the page said. This rule stops that across every future run for about 2 minutes of work. DO TODAY: in the repo root, run:

```
cat >> CLAUDE.md <<'EOF'

## Connector failures
A failed connector read (Gmail, journal, GitHub, Notion) is not evidence about its contents. Say what failed: the item is missing, the connection lacks permission, or the request timed out. Then stop that step. Never guess what an email, post or page says.
If an action fails through a connector: try a different call, then another tool, and only then flag the blocker in the run transcript.
EOF
git add CLAUDE.md && git commit -m "Add connector-failure rule" && git push origin main
```

Then check tomorrow's transcript: any failed read should be named, not filled in.
