**WORKFLOW — "Farmer Claude": Claude Code on a Raspberry Pi 4 woke itself by cron to keep seedlings alive.** Source: Tal Raviv's Substack, "I had Fable grow my food" (talraviv.co/p/fable-grows-my-food). **CONCEPT — Two review gates between demo and production: "can we contain the agent" and "will the vendor allow it".** Source: The Chai & AI Community Substack, "Navigating Security Reviews and Vendor APIs" (Jacob Chacko session). Internal gate: separate reversible transactions from master data (keep bank details, credit limits and approval thresholds read-only); put an idempotency key on every state-changing request, because a lost response plus a retry can create two permanent ledger entries; keep segregation of duties (one agent creates the vendor, a different one with separate credentials pays); treat free-text fields as untrusted; pin the model version, version every prompt like code, and log prompt, output and retrieved context. Vendor gate: agentic integration can become "ontology extraction", because an agent learns the whole data model, not just the net value. Four integration paths ranked: published APIs, vendor-endorsed agent gateways, community connectors, undocumented interfaces (prototypes only). Action: add an idempotency key and a retry cap to your Lead Analysis Workflow (see Top Thing).
