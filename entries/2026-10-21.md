**WORKFLOW — The Gauntlet Loop: build, then let independent critics judge against a real reference.** Source: Ultrathink (Tenex Media), "Humans are slowing agents down." Matt Shumer's method: give the agent something real to beat (screenshots of an excellent site, writing you admire, a test suite), split the job into pieces a subagent can build and judge separately, give each piece a critic that starts with fresh context and judges blind where possible, and loop until improvements plateau. Shumer built a Call of Duty-style shooter from a three-paragraph prompt (20 million+ views on X; prompt and code at github.com/mshumer/Claude-of-Duty; guide at tenex.co/playbooks/gauntlet-loop). Prompt for Claude Code or Codex: "Build [what you want]. Use [reference] as the standard to match or beat. Break the work into pieces that can be judged on their own. For each piece, have one agent build it. Have a separate critic start with fresh context and compare the actual result against the reference, blind where possible. If ours loses, fix the biggest gap and compare again. Repeat until ours wins or improvements plateau." Caveat: an independent critic is not necessarily a correct one. Why it matters: agents are generous graders of their own work. Who: anyone running Claude Code on writing, design or code quality. Action: see Top Thing.

**NEWS — Meta's Muse shared chats were findable through passive DNS records; Meta paused sharing.** Source: The Neuron (theneurondaily.com/p/meta-s-muse-made-shared-chats-searchable-a190), citing Claroc (blog.claroc.io/ghostshares-muse-passive-dns/) and The Verge. Muse builds each share URL from the chat title plus a random code (e.g. q3-budget-review-4d7a19e2), and the full hostname is logged in passive DNS the first time anyone opens it, so Claroc found 6,800+ share addresses without ever being sent a link. Samples included a job candidate's prep notes for a frontier lab call, a loan application and a staff vacation calendar. Muse passed 10.9M downloads in 40 days (Sensor Tower via TechCrunch). Claroc sells AI-sharing risk software and covered one lookup service and a short window; it reports no evidence of misuse, and it reported to Meta's bug bounty on October 8. Why it matters: "unlisted" link sharing leaks through DNS. Who: anyone building a share-link feature or sharing AI chats. Action: never put titles or identifiers in a hostname; share sensitive chats only as screenshots or text.

**CONCEPT — Every Agent: replace a fleet of personal agents with one shared agent; put permission rules in code, not in the prompt.** Source: Every, "Why We Replaced Personal Agents With One for the Whole Company" (Willie Williams). Every deleted 86,730 lines of its Plus One personal-agent code on May 12, moved infrastructure to Claude Managed Agents and launched Every Agent publicly on October 6. Three design fixes: (1) conversations, with a small fast model checking each thread message to decide whether it needs an answer, and Slack kept as the official record; (2) connections, where tasks attach to a "slot" any matching login can fill so a Monday report survives a departing employee; (3) permissions, enforced in code so the model cannot be talked into editing someone else's skill. The consent check compares the agent's request against what the person actually wrote in Slack. Reversibility test from engineer Will Gathright: if it is easy to undo, act and state assumptions; if it is destructive or visible outside the conversation, ask first. Cost of encoded rules: a July migration made all 24 shared skills private until 9 were reopened. Who: anyone building a team agent. Action: list your routine's irreversible steps and enforce an approval for each outside the prompt.
