**WORKFLOW — Andrew Ng published a five-skill framework for using coding agents, arguing review and verification, not code generation, is now the bottleneck.** Source: thebatch@deeplearning.ai, 2026-09-04, "Using Coding Agents, The Most Rapidly-Evolving Core AI Engineering Skill."
