**CONCEPT — Anthropic research: per-user agents sharing one resource did far worse than a single coordinator, 30% vs 64% of the best outcome (Claude Opus 5).** Source: The Neuron (Intelligent Insights). Paper: alignment.anthropic.com/2026/worse-together, by Sahan Paliskara and colleagues. Each agent acting for its own user on a shared resource ends up competing for it; one coordinator that sees every request does about twice as well in that test. Why it matters: it is the cautionary side of Every's Level 9/10 "competing agent teams" from 11-13. Who: anyone giving several agents (or several teammates' agents) access to one calendar, budget, repo or queue. Action: if two of your routines write to the same place, route both through one coordinator step instead of letting each write directly.

**WORKFLOW — Plan with a strong model, execute step by step on Gemini 4 Hydrogen.** Source: The Neuron (AI Skill of the Day), The Rundown AI, ultrathink. Hydrogen is Google's fast, cheaper model for coding and agent work, built from Gemini 4 Carbon, with four thinking levels: low, medium, high (default) and xhigh (new). It is in the Gemini app dropdown, the Gemini API and AI Studio, and is now in Search for all users. Google's Antigravity Orchestrator switches between Carbon and Hydrogen and, by Google's own tests, gets near-Carbon results with about 24% less quota and 19% faster completion; the 2.5x speed claim was measured against Gemini 3.8 Flash. The Neuron's planning prompt: "I'm going to hand this job to a fast model one step at a time, so write the plan for it. Job: [...] Break it into numbered steps. For each step, give me: an instruction that makes sense on its own; the input it needs from earlier steps; a one-line 'done looks like' check. Mark any step that needs real judgment, not just execution." Only failed steps go back to the big model. Why it matters: it is the same split as Opus vs Fable (11-11, 11-13): pay for reasoning only where it is needed. Who: anyone with a repeated multi-step job. Action: run the prompt once on Opus, then execute the steps on a cheaper model and count how many bounce back.
